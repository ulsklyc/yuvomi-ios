# Support

Yuvomi for iOS is a solo-maintained open-source project. Pick the channel that fits:

- **Questions & ideas** - [Yuvomi Discussions](https://github.com/ulsklyc/yuvomi/discussions) in the
  server repository; the app and the server share one place for that. Feature ideas go to the
  [Ideas category](https://github.com/ulsklyc/yuvomi/discussions/new?category=ideas);
  issues are reserved for bugs.
- **Bugs in the app** - [open a bug report](https://github.com/ulsklyc/yuvomi-ios/issues/new/choose) here.
  Please fill in the app build, the iOS version and the server version - they decide where to look first.
- **Bugs in the server or the web app** - if the web app shows the same problem, it is a server bug:
  [report it in the server repository](https://github.com/ulsklyc/yuvomi/issues/new/choose).
- **Security vulnerabilities** - never a public issue: use
  [private vulnerability reporting](https://github.com/ulsklyc/yuvomi-ios/security/advisories/new)
  (see [SECURITY.md](SECURITY.md)).
- **Setup help** - the README covers [building the app](README.md#build-from-source) and
  [which server it needs](README.md#questions); setting up the server itself is covered in the
  [server repository](https://github.com/ulsklyc/yuvomi).

Expect answers within a few days - this is one person's evenings, not a support desk.
